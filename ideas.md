# Dirección de diseño — Maximiliano Fallini Portfolio

## Movimiento de diseño
Minimalismo editorial técnico: una interfaz oscura, silenciosa y precisa que combina la sobriedad de una terminal con el ritmo de una publicación de diseño.

## Principios
- Mucho espacio negativo y jerarquía tipográfica fuerte.
- Verde neón como señal de actividad, no como decoración constante.
- El contenido propio tiene prioridad: solo dos proyectos curados.
- El fondo es vivo y atmosférico, inspirado en akkila.dev, pero implementado como una red de partículas original que responde al cursor.

## Color y layout
Negro verdoso como base, gris pizarra para texto secundario y verde lima para acciones, estados y acentos. Layout por secciones con una grilla editorial, bordes finos y tarjetas de proyecto de gran formato.

## Elementos de firma
Marca MC de tres barras ascendentes, órbita de código en el Hero, numeración 01/02/03 y microcopy en mayúsculas monoespaciadas.

## Tipografía y voz
Manrope para titulares y texto; DM Mono para etiquetas, metadatos y navegación. Voz directa, reflexiva, técnica y cálida.

## Identidad
El símbolo MC representa crecimiento, sistema y ejecución. El verde neón es la firma visual del portafolio.
